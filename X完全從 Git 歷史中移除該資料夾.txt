完全從 Git 歷史中移除該資料夾

# 1.請先在github上建立您的repository

# 2. 請使用 cmd 並切換(cd)至您的專案資料夾內

# 3. 請先確認是否已經安裝過套件 filter-repo, 若無請執行以下指令:

pip install git-filter-repo
